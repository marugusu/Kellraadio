# Varundus ja kolimine (Backup & Migration)

Kellraadio eristab teadlikult süsteemset automaatvarundust ja käsitsi failipõhist kolimist. Androidi Auto Backup ja seadmeülekanne (`backup_rules.xml`, `data_extraction_rules.xml`) välistavad Roomi andmebaasi privaatsuse ning selle tõttu, et taustal taastatud äratused ei tekitaks uues seadmes ootamatut äratuste käivitumist ilma kasutaja teadliku kinnituseta. Käsitsi eksporditav JSON-varundus (`BackupData`) koondab **Minu jaamad** (ajaloolise JSON-võtmega `customStations`), **Kureeritud jaamade** **Lemmikud**, äratused (sealhulgas `recordAudio` lipu) ja `SettingsScreen`-i püsiseaded, välistades suure mahu tõttu **Salvestised**, **Laulude ajalugu** ning seansi hetkeoleku (`last_category`, `last_selected_id`). Ühilduvuse tagamiseks kasutab varunduse JSON-koodek valikuid `ignoreUnknownKeys = true` ja `encodeDefaults = true`, kureeritud **Lemmikuid** sobitatakse taastamisel järjekorras `id` → `url` → täpne `name` (teavitades kasutajat leidmata jäänud jaamadest), ning import valideerib faili enne kinnitusdialoogi ja töötab puhta asendamisena (Replace).
