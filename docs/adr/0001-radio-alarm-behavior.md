# Raadioäratuse helikäitumine ja disain

Äratusfunktsioon käivitab valitud raadiojaama tavapärase meediamängijana (`USAGE_MEDIA`) kasutaja määratud viimase helitugevusega, ilma helitugevust automaatselt muutmata või kohalikku vaikehelina varuäratust (fallback ringtone) ega eraldiseisvat täisekraani äratusakent kasutamata. See tagab, et Kellraadio käitub nagu klassikaline kellraadio, kus äratusena kõlab puhas raadiojaam täpselt samal helitugevusel, mille kasutaja magama minnes jättis.
